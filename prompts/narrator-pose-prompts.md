# Narrator "explainer" poses (pop-up presenter)

The narrator pops into the corner of the screen and "explains," like a host, next to a text card, an icon or a chart.

## How to use

1. Open a new Nano Banana chat and attach `reference/characters/narrator.png`.
2. Paste the **SETUP**, then each prompt. Choose **2K**, and save the images as `N01.jpg`, `N02.jpg`, and so on.
3. Upload them to a folder called `narrator/` on GitHub (or send them to Claude in chat).

## SETUP

```
I need the same character in different poses, for cut-out use in a video. Use the attached narrator EXACTLY: a glowing peach brain head with two white oval eyes and no mouth, a black hoodie, black pants, black hands, and white sneakers with a red stripe. Same proportions and line style every time.
Every image: full body, centered, on a PURE WHITE background (#FFFFFF) with NO shadow, NO floor, NO other objects, NO text. Clean thick outlines. 16:9, 2K.
Reply "ready" and wait for my first pose.
```
