# Icon prompts: "The Psychology of Self-Doubt"

**8 new icons (I71–I78).** The others (I06, I11, I41, I52, I63, I67) are reused and already in `icons/`.

## How to use

1. Open a **new** Nano Banana chat. Attach 2 old icons as examples (`reference/style/icon-example-1.jpg` and `icon-example-2.jpg`).
2. Paste the **SETUP**, then the prompts one at a time, choosing **2K**.
3. Name each file exactly as shown, **starting with I** (`I71.jpg` …). Put them in **Icons Vid5** in Downloads.

## SETUP

```
I'm making quick "cutaway" icons for a YouTube explainer. Every image in this chat must match the attached example icons exactly:
one simple centered subject on a plain off-white background (#FAF7F0), clean thick black outlines, flat colors with a little soft shading, lots of empty space around the subject, friendly and simple. 16:9, 2K. NO text, NO words, NO letters, NO numbers anywhere.
Reply "ready" and wait for my first prompt.
```
