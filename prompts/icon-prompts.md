# Icon prompts: "The Psychology of Discipline"

**9 new icons (I99, I101–I108).** I78, I80, I84 and I86 are reused and already in `icons/`.

## How to use

1. Open a **new** Nano Banana chat. Attach 2 old icons as examples (`reference/style/icon-example-1.jpg` and `icon-example-2.jpg`).
2. Paste the **SETUP**, then the prompts one at a time. 1K is fine for icons, so you can bulk download.
3. **Rename each file exactly as shown** (`I99.jpg` …), or send them in this order. Put them in **Icons Vid8** in Downloads.

## SETUP

```
I'm making quick "cutaway" icons for a YouTube explainer. Every image in this chat must match the attached example icons exactly:
one simple centered subject on a plain off-white background (#FAF7F0), clean thick black outlines, flat colors with a little soft shading, lots of empty space around the subject, friendly and simple. 16:9. NO text, NO words, NO letters, NO numbers anywhere.
Reply "ready" and wait for my first prompt.
```
